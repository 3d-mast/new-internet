## Следующий слой: полноценная виртуальная сеть

Планируемый dataplane:

1. TUN/Wintun получает IPv6-пакет ОС.
2. Таблица маршрутов выбирает peer/path.
3. Пакеты агрегируются в короткие зашифрованные datagram-фреймы.
4. Path manager отправляет их через QUIC direct, UDP hole punch или relay.
5. Capability engine проверяет доступ до передачи в TUN/exit/LAN.

Контрольный слой останется совместимым с текущей идентичностью и приглашениями.
